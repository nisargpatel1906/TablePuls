# Security Policy

## Supported Versions
| Version | Supported |
|---|---|
| `1.0.x` / `main` | Yes |

## Reporting a Vulnerability
**Do not open public GitHub issues for security vulnerabilities** (especially authentication/RBAC bypasses, RTSP credential exposure, SSRF, or privacy/face-blurring failures).

Please report security issues privately using **GitHub Security Advisories** on `https://github.com/nisargpatel1906/TablePuls/security/advisories/new`.

- **Acknowledgment Target**: Within 72 hours.
- **Triage & Fix**: Critical/high vulnerabilities are prioritized immediately with coordinated disclosure once a patched release is available.
