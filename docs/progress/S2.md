# Stage 2 Progress Report — Auth, RBAC, Account Lifecycle & Audit Logging

## 1. Deliverables Created/Modified
- `backend/app/core/errors.py`: Canonical `{ success: true, data }` / `{ success: false, error: { code, message, fields? } }` handlers (`400`/`401`/`403`/`404`/`409`/`422`/`429`/`500`).
- `backend/app/core/logging.py`: Structured JSON logging (`structlog`) with secret/token/RTSP-credential scrubbing (`scrub_text`, `scrub_mapping`).
- `backend/app/core/security.py`: Argon2id (`time_cost=3, memory_cost=65536, parallelism=4`), password strength (`>=12` chars, `zxcvbn >= 3`, breach list), JWT access tokens (`15m`), opaque 256-bit refresh/invite/reset tokens (SHA-256 hashed), AES-256-GCM field encryption, TOTP RFC 6238, stream tokens, HMAC webhook signatures.
- `backend/app/core/rbac.py`: `packages/rbac/matrix.yaml` SSoT loader, separated AuthN (`get_current_user` -> `401`) and AuthZ (`require_venue_role`, `require_org_role` -> `403`).
- `backend/app/core/valkey_client.py`: Valkey 8 rate limiting (fail-closed in-process fallback for auth), user revocation pub/sub, kill-switch cache, idempotency cache.
- `backend/app/api/auth.py`: `API-001`–`API-006`, invite-info, accept-invite, `/me`.
- `backend/app/api/org_users.py`: `API-021` (`/org/users`, `/org/users/invite`, `/org/users/{id}`, `/revoke-sessions`, `/reset-link`, `/org/audit-logs` JSON + formula-safe CSV).
- `backend/app/cli.py`: `tablepulse admin` CLI (`revoke-all`, `rotate-keys`, `backup`, `restore`).
- `backend/app/main.py`: FastAPI app, CORS, security headers, Prometheus `/metrics`, `/api/v1/health`.
- `backend/tests/test_auth_and_rbac.py`.
