# Stage N7 Report — Public Customer Digital Menu API (`API-035`) & Isolated UI (`SCR-022`)

## Summary
- Implemented unauthenticated read-only **API-035** (`backend/app/api/public_menu.py` + `backend/app/schemas/public_menu.py`):
  - Queries PostgreSQL strictly via `get_public_db()` (`tablepulse_public` read-only role on `v_public_qr_resolution` & `v_public_menu_catalog`).
  - Validates strict `PublicMenuResponse` allowlist (`extra="forbid"`, zero organization/venue/table IDs, zero RTSP/staff fields, zero `Set-Cookie`).
  - Handles `404 QR_CODE_NOT_FOUND`, `410 QR_CODE_REVOKED` (rotated or expired grace), `410 TABLE_UNAVAILABLE`, signed preview tokens `?p=`, read-time `unavailable_until` auto-restore, timezone-aware schedule matching, Valkey 60s cache + 24h stale-while-error fallback (`X-Stale: 1`) + Valkey-down in-process fallback, `ETag`/`304`, `60 req/min` fail-open IP rate limiting, and non-blocking privacy-safe debounced daily scan counting using an ephemeral daily memory salt.
- Implemented **SCR-022** (`frontend/src/app/(public)/m/[qrToken]/page.tsx`, `frontend/src/components/PublicDigitalMenu.tsx`, `frontend/src/components/ClientProviders.tsx`):
  - Complete auth/cookie/shell isolation: `/m/*` bypasses `AuthProvider` and `AppShell` entirely and sends requests with `credentials: "omit"`, `referrerPolicy: "no-referrer"`.
  - Mobile-first Light & Dark + EN/HI read-only digital menu with sticky search, dietary filter chips, category jump links, lazy WebP thumbnails, `Sold Out` badges, dish detail bottom sheet (allergens, prep time, calories, variants), graceful paused/revoked/404 states, and strict security headers in `next.config.ts` & `infra/caddy/Caddyfile` (`noindex, nofollow`, `no-referrer`, `X-Frame-Options: DENY`, `frame-ancestors 'none'`).
