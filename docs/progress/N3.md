# Stage N3 Report — Advanced Table Management Backend (`API-024`, `API-025`)

## Summary
- Implemented `backend/app/core/validation.py` (`clean_text`, `clean_optional_text`, `normalize_table_code`, `is_valid_qr_token`, `normalize_bulk_prefix`), `backend/app/schemas/tables_qr.py`, and `backend/app/api/tables_admin.py` mounted on FastAPI app (`backend/app/main.py`):
  - `GET /api/v1/venues/{venue_id}/tables`: paginated, searchable, filterable (status active/inactive/all, section, camera mapped/unmapped) with active QR token/URL/scan stats and summary totals (`tables.read`).
  - `POST /api/v1/venues/{venue_id}/tables`: individual table creation (`min_capacity <= seat_capacity`, 500-table venue cap `422 LIMIT_EXCEEDED`, `Idempotency-Key`, duplicate active `table_code` -> `409 DUPLICATE_TABLE_CODE`, fail-closed `TABLE_ADVANCED_ENABLED`), atomically creating an `ACTIVE` 128-bit CSPRNG `table_qr_codes` row + `TABLE_CREATED` audit log + WebSocket `table.created`.
  - `PATCH /api/v1/venues/{venue_id}/tables/{table_id}`: optimistic-lock checked (`409 VERSION_CONFLICT`), preserves existing QR code on rename while evicting Valkey cache & incrementing `venues.menu_revision`, supports deactivating/reactivating & camera unlink, logs `TABLE_UPDATED`/`TABLE_DEACTIVATED`.
  - `DELETE /api/v1/venues/{venue_id}/tables/{table_id}`: active-session/waitlist delete guard (`409 TABLE_IN_USE` unless `force=true`), atomically soft-deletes table, revokes active/grace QR codes (`TABLE_DELETED`), resolves open alerts, evicts cache, notifies CV worker `roi.updated`, frees `table_code` for reuse, logs `TABLE_DELETED`.
  - `POST/PATCH /api/v1/venues/{venue_id}/tables/bulk`: atomic all-or-nothing 1–50 table generation with collision pre-check + auto QR provisioning, and bulk section / active status toggles.
- Extended `GET/PUT /api/v1/venues/{venue_id}/cameras/{camera_id}/polygons` in `venues_cameras.py` to return `unassigned_tables` for 1-click calibration binding in `SCR-013` and auto-provision QR rows for newly drawn polygon tables.
- Added `evict_public_qr_cache`, `evict_public_menu_cache`, `cache_get_json`, and `cache_set_json` in `backend/app/core/valkey_client.py`.
