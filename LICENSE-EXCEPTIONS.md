# License Exceptions Register

No third-party license exceptions are active in TablePulse v1.0.

All runtime and build dependencies must conform strictly to `config/license-allowlist.yaml` (Apache-2.0, MIT, BSD-2/3-Clause, ISC, PSF, PostgreSQL, MPL-2.0, CC0, Unlicense). Any future exception requires explicit maintainer and legal counsel sign-off (`PR-04`/`PR-05`) before merge.
